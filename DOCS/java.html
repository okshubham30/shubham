1. Introduction to Java

Java is a high-level, object-oriented, class-based programming language designed to be portable across platforms.

Core idea: Java source code is compiled into bytecode, and the JVM executes that bytecode.

Object-Oriented

Programs are organized around classes and objects.

Platform Independent

Java bytecode can run on systems having a compatible JVM.

Strongly Typed

Variables have defined data types.

DSA Friendly

Collections such as ArrayList, HashMap and PriorityQueue are heavily used in DSA.

11. Methods

Methods are reusable blocks of code.

static int add(int a, int b) {
    return a + b;
}

public static void main(String[] args) {
    int result = add(10, 20);
    System.out.println(result);
}

Method Overloading

static int add(int a, int b) {
    return a + b;
}

static double add(double a, double b) {
    return a + b;
}
Java is pass-by-value. For objects, the value passed is the reference value.

15. Inheritance

Inheritance allows a class to acquire members and behavior from another class.

class Animal {
    void eat() {
        System.out.println("Eating");
    }
}

class Dog extends Animal {
    void bark() {
        System.out.println("Barking");
    }
}

public class Main {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.eat();
        d.bark();
    }
}

Java classes support single, multilevel and hierarchical inheritance. Multiple inheritance of classes is not supported; interfaces can provide multiple type inheritance.

16. Polymorphism

Compile-Time Polymorphism — Overloading

class Calculator {
    int add(int a, int b) {
        return a + b;
    }

    int add(int a, int b, int c) {
        return a + b + c;
    }
}

Runtime Polymorphism — Overriding

class Animal {
    void sound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Bark");
    }
}

Animal a = new Dog();
a.sound();

17. Abstraction

Abstraction focuses on essential behavior while hiding implementation details.

abstract class Vehicle {
    abstract void start();

    void stop() {
        System.out.println("Vehicle stopped");
    }
}

class Car extends Vehicle {
    @Override
    void start() {
        System.out.println("Car started");
    }
}

34. Important Java Interview / Revision Questions

QuestionQuick Answer
What is Java?A high-level, class-based, object-oriented programming language.
JDK vs JRE vs JVM?JDK is for development, JRE is runtime environment, JVM executes bytecode.
What is a class?A blueprint that defines state and behavior.
What is an object?An instance of a class.
What is inheritance?A mechanism through which a class derives from another class.
Overloading vs overriding?Overloading changes method parameters; overriding redefines inherited behavior.
What is encapsulation?Bundling data and methods while controlling access.
What is abstraction?Showing essential behavior while hiding implementation details.
ArrayList vs LinkedList?Both are lists; their performance characteristics differ for indexed access and insertion/removal patterns.
HashMap use?Fast average-case key-value lookup and frequency counting.
What is recursion?A method solving a problem by calling itself on smaller subproblems.
What is Big-O?A way to describe how time or space requirements grow with input size.
Java DSA Revision Order:
Basics → Conditions → Loops → Methods → Arrays → Strings → OOP → Recursion → Collections → Sorting → Searching → Linked List → Stack → Queue → Hashing → Trees → Heap → Graph → DP.
