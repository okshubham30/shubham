1. Introduction to Python

Python is a high-level, general-purpose programming language known for readable syntax and a large ecosystem. It is widely used in web development, automation, data analysis, AI/ML, scripting and backend development.

Python philosophy: readable code, simple syntax and reusable components.

Web Development

Django, Flask and FastAPI are popular Python web frameworks.

Automation

Python can automate repetitive file, browser, data and system tasks.

Data & AI

Python has a huge ecosystem for data analysis, scientific computing and machine learning.

2. Installing and Running Python

Python programs are commonly saved with the .py extension.

print("Hello, Python!")

Run a file from a terminal:

python app.py

Check the installed Python version:

python --version
Tip: Use a code editor such as VS Code and create a separate virtual environment for each project.

4. Variables

Variables are names bound to objects. Python does not require a separate variable-type declaration.

Variable Naming Rules

  • Cannot start with a digit.
  • Names are case-sensitive.
  • Do not use Python keywords as variable names.

24. Magic / Dunder Methods

Special methods use double underscores and integrate classes with Python's data model.

class Book:
    def __init__(self, title):
        self.title = title

    def __str__(self):
        return self.title

    def __len__(self):
        return len(self.title)

book = Book("Python")
print(book)
print(len(book))

Common examples include __init__, __str__, __repr__, __len__, __eq__ and arithmetic special methods.

26. Generators

Generators use yield to produce values lazily.

def count_up_to(n):
    i = 1
    while i <= n:
        yield i
        i += 1

for value in count_up_to(5):
    print(value)
Generators are especially useful when processing large or streaming data because values can be produced one at a time.

27. Decorators

A decorator wraps a function or callable to add behavior without changing its core implementation.

def logger(func):
    def wrapper(*args, **kwargs):
        print("Calling function...")
        result = func(*args, **kwargs)
        print("Done")
        return result
    return wrapper

@logger
def greet(name):
    print(f"Hello {name}")

greet("Shubham")

Decorators are common in frameworks for authentication, logging, caching and routing.

33. Multithreading

Threads are useful for many I/O-bound tasks where work spends time waiting.

import threading

def task():
    print("Task running")

t = threading.Thread(target=task)
t.start()
t.join()

In standard CPython, the GIL limits simultaneous execution of Python bytecode across threads, so threads are not generally the first choice for CPU-bound Python code.

34. Multiprocessing

Multiprocessing uses separate processes and can provide true parallelism for CPU-heavy work.

from multiprocessing import Process

def task():
    print("Process running")

if __name__ == "__main__":
    p = Process(target=task)
    p.start()
    p.join()
Protect process-starting code with if __name__ == "__main__":, especially on platforms that use spawn-based process creation.

38. Python Best Practices

  • Use meaningful variable and function names.
  • Follow consistent formatting and indentation.
  • Keep functions focused on one responsibility.
  • Prefer readable code over clever code.
  • Use virtual environments for projects.
  • Handle expected exceptions specifically.
  • Keep secrets out of source code.
  • Write tests for important logic.
  • Use version control such as Git.
  • Document public APIs and complex decisions.

40. Full Python Example — Expense Tracker

This small project combines input, functions, lists/dictionaries, loops and file handling.

import json
from pathlib import Path

FILE = Path("expenses.json")

def load_expenses():
    if not FILE.exists():
        return []
    return json.loads(FILE.read_text(encoding="utf-8"))

def save_expenses(expenses):
    FILE.write_text(
        json.dumps(expenses, indent=2),
        encoding="utf-8"
    )

def add_expense(expenses):
    title = input("Title: ")
    amount = float(input("Amount: "))

    expenses.append({
        "title": title,
        "amount": amount
    })

def show_expenses(expenses):
    if not expenses:
        print("No expenses found.")
        return

    total = 0

    for item in expenses:
        print(f"{item['title']}: ₹{item['amount']:.2f}")
        total += item["amount"]

    print(f"Total: ₹{total:.2f}")

def main():
    expenses = load_expenses()

    while True:
        print("\n1. Add expense")
        print("2. Show expenses")
        print("3. Exit")

        choice = input("Choose: ")

        if choice == "1":
            add_expense(expenses)
            save_expenses(expenses)

        elif choice == "2":
            show_expenses(expenses)

        elif choice == "3":
            print("Goodbye!")
            break

        else:
            print("Invalid choice.")

if __name__ == "__main__":
    main()

  • Functions and modular design
  • Lists and dictionaries
  • Loops and conditions
  • Input validation basics
  • JSON file storage
  • pathlib
  • if __name__ == "__main__"
