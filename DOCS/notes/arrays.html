01 • FOUNDATION

Array Basics

1. What is an Array?

An array is a collection of elements of the same data type stored in contiguous memory locations. Each element is accessed using an index.

Simple meaning: An array stores many values of the same type under one variable name.
int marks[5] = {78, 85, 91, 67, 88};

2. Important Terminology

TermMeaning
ElementA value stored in the array.
IndexPosition used to access an element.
SizeNumber of elements the array can contain.
Base AddressAddress of the first element.
Contiguous MemoryElements are stored next to each other.

3. Indexing

int a[5] = {10,20,30,40,50};

Index:   0   1   2   3   4
Value:  10  20  30  40  50

C uses zero-based indexing, so a[2] is 30.

4. Declaration & Initialization

int a[5];
int b[5] = {10,20,30,40,50};
int c[] = {1,2,3,4};
02 • ONE DIMENSION

One-Dimensional Array

5. Concept

A 1D array is a linear sequence of elements.

10  20  30  40  50
↑   ↑   ↑   ↑   ↑
0   1   2   3   4

6. Traversal

#include <stdio.h>

int main() {
    int a[5] = {10,20,30,40,50};
    for(int i=0; i<5; i++)
        printf("%d ", a[i]);
    return 0;
}
Traversal = O(n)

7. 1D Address Formula

LOC(A[i]) = Base + W × (i − LB)

For zero-based indexing: LOC(A[i]) = Base + W × i

8. Example

Base = 1000
W = 4 bytes
Find A[6]

LOC(A[6]) = 1000 + 4×6
           = 1024
Answer = 1024

05 • MEMORY REPRESENTATION

Row-Major Representation

16. Concept

The complete first row is stored first, then the second row, and so on.

1 2 3
4 5 6
7 8 9

Memory:
1 → 2 → 3 → 4 → 5 → 6 → 7 → 8 → 9
Important: C stores multidimensional arrays in row-major order.

17. Formula

LOC(A[i][j]) = Base + W × (i × N + j)

N = number of columns, W = element size in bytes.

18. Numerical

A[3][4], Base=1000, W=4
Find A[2][3]

= 1000 + 4 × (2×4 + 3)
= 1000 + 44
= 1044
Answer = 1044
06 • MEMORY REPRESENTATION

Column-Major Representation

19. Concept

The complete first column is stored first, then the second column, and so on.

1 2 3
4 5 6
7 8 9

Memory:
1 → 4 → 7 → 2 → 5 → 8 → 3 → 6 → 9

20. Formula

LOC(A[i][j]) = Base + W × (j × M + i)

M = number of rows.

21. Numerical

A[3][4], Base=1000, W=4
Find A[2][3]

= 1000 + 4 × (3×3 + 2)
= 1000 + 44
= 1044
Exam Tip: Do not assume row-major and column-major formulas are the same just because one numerical gives the same answer.
FeatureRow MajorColumn Major
StorageRow by rowColumn by column
FormulaBase + W(iN+j)Base + W(jM+i)
CYesNot normal C layout
07 • NUMERICALS

Address Calculation

22. Formula Sheet

1D: LOC(A[i]) = Base + W(i − LB)
Row Major: LOC(A[i][j]) = Base + W(iN + j)
Column Major: LOC(A[i][j]) = Base + W(jM + i)

23. Numerical

B[4][5], Base=2000, W=2
Find row-major address of B[3][4]

= 2000 + 2 × (3×5 + 4)
= 2000 + 38
= 2038
Answer = 2038

24. Steps for AKTU Numericals

  1. Identify rows and columns.
  2. Identify base address.
  3. Identify element size.
  4. Check lower bound/indexing.
  5. Choose row-major or column-major.
  6. Substitute carefully.
08 • SPARSE MATRIX

Sparse Matrix

25. Definition

A matrix in which most elements are zero is called a sparse matrix.

0 0 0 7
0 0 0 0
5 0 0 0
0 0 9 0

Total elements = 16; non-zero = 3; zero = 13.

Key idea: Storing every zero wastes memory. Sparse representations store only significant values.

26. Advantages

  • Saves memory.
  • Reduces unnecessary processing.
  • Useful for large mathematical/scientific data.
  • Useful in graphs, images and datasets with many zero values.

27. Sparse vs Dense

SparseDense
Mostly zerosMany non-zero values
Compact representation usefulNormal matrix often sufficient
Stores significant values efficientlyStores all values
09 • REPRESENTATION

Triplet / 3-Tuple Representation

28. Concept

For every non-zero value, store row, column and value. The first row commonly stores rows, columns and the number of non-zero elements.

Original:
0 0 3
0 0 0
4 0 0
0 5 0

Triplet:
Row Column Value
 4    3      3   ← metadata
 0    2      3
 2    0      4
 3    1      5

29. C Structure

struct Term {
    int row;
    int col;
    int value;
};

struct Term sparse[20];

30. Conversion Logic

for(i=0; i<rows; i++)
    for(j=0; j<cols; j++)
        if(matrix[i][j] != 0) {
            /* store i, j and matrix[i][j] */
        }
10 • OPERATION

Sparse Matrix Transpose

31. Transpose

Transpose swaps rows and columns.

1 2 3        1 4
4 5 6   →    2 5
             3 6

32. Triplet Transpose

(row, column, value) → (column, row, value)
(1,3,7) → (3,1,7)

33. Example

Original:
(0,2,3)
(2,0,4)
(3,1,5)

Transpose:
(2,0,3)
(0,2,4)
(1,3,5)
m × n matrix → n × m transpose
11 • AKTU REVISION

Exam Notes & Final Cheat Sheet

34. Must-Remember Definitions

  • Array = same-type elements stored in contiguous memory.
  • 1D array = linear list.
  • 2D array = rows and columns.
  • Row-major = row by row storage.
  • Column-major = column by column storage.
  • Sparse matrix = mostly zero elements.
  • Triplet = row, column and value of non-zero elements.

35. Must-Remember Formulas

1D: LOC(A[i]) = Base + W(i − LB)
Row Major: LOC(A[i][j]) = Base + W(iN + j)
Column Major: LOC(A[i][j]) = Base + W(jM + i)

36. Memory Trick

ROW MAJOR    → Row × Columns + Column
                i × N + j

COLUMN MAJOR → Column × Rows + Row
                j × M + i
