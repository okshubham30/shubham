01 • LIFO DATA STRUCTURE

Stack

Definition: A stack is a linear data structure in which insertion and deletion take place only at one end called the TOP. It follows the LIFO (Last In, First Out) principle.

LIFO Concept

The element inserted last is removed first.

Real-life exampleA stack of plates: the last plate placed on top is the first plate removed.

Basic Terminology

  • TOP: Points to the element currently at the top of the stack.
  • Push: Inserts an element at the top.
  • Pop: Removes the top element.
  • Peek/Top: Reads the top element without deleting it.
  • Overflow: Trying to push into a full stack.
  • Underflow: Trying to pop from an empty stack.

Stack Representation

TOP
 ↓
[40]
[30]
[20]
[10]
─────
Bottom
Remember: Stack = LIFO = insertion/deletion from the same end.
02 • ARRAY IMPLEMENTATION

Stack Using Array

A stack can be implemented using a one-dimensional array and an integer variable top.

Initial Condition

top = -1

When top = -1, the stack is empty.

Push Operation

  1. Check whether top == MAX-1.
  2. If true, report Stack Overflow.
  3. Otherwise increment top.
  4. Store the new item at stack[top].

Pop Operation

  1. Check whether top == -1.
  2. If true, report Stack Underflow.
  3. Otherwise read stack[top].
  4. Decrement top.

Peek Operation

If the stack is not empty, stack[top] gives the top element without removing it.

C Program — Stack Using Array
#include <stdio.h>
#define MAX 5

int stack[MAX];
int top = -1;

void push(int value)
{
    if (top == MAX - 1)
        printf("Stack Overflow\n");
    else
    {
        top++;
        stack[top] = value;
    }
}

void pop()
{
    if (top == -1)
        printf("Stack Underflow\n");
    else
    {
        printf("Deleted: %d\n", stack[top]);
        top--;
    }
}

void peek()
{
    if (top == -1)
        printf("Stack is Empty\n");
    else
        printf("Top: %d\n", stack[top]);
}

int main()
{
    push(10);
    push(20);
    push(30);

    peek();
    pop();
    peek();

    return 0;
}

Complexity

PushO(1)
PopO(1)
PeekO(1)
SpaceO(n)
03 • LINKED IMPLEMENTATION

Stack Using Linked List

A linked-list stack uses nodes. The top pointer points to the first node, and insertion/deletion are performed at the beginning.
TOP
 ↓
[30 | next] → [20 | next] → [10 | NULL]

Push in Linked-List Stack

  1. Create a new node.
  2. Store the value in the node.
  3. Make newNode->next = top.
  4. Set top = newNode.

Pop in Linked-List Stack

  1. Check whether top == NULL.
  2. Store the current top node in a temporary pointer.
  3. Move top = top->next.
  4. Free the old top node.
C Program — Stack Using Linked List
#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

struct Node *top = NULL;

void push(int value)
{
    struct Node *newNode =
        (struct Node*)malloc(sizeof(struct Node));

    newNode->data = value;
    newNode->next = top;
    top = newNode;
}

void pop()
{
    if (top == NULL)
        printf("Stack Underflow\n");
    else
    {
        struct Node *temp = top;
        printf("Deleted: %d\n", temp->data);
        top = top->next;
        free(temp);
    }
}

void peek()
{
    if (top == NULL)
        printf("Stack is Empty\n");
    else
        printf("Top: %d\n", top->data);
}

int main()
{
    push(10);
    push(20);
    push(30);

    peek();
    pop();
    peek();

    return 0;
}
Advantage: A linked-list stack does not need a fixed array capacity. It grows dynamically until available memory is exhausted.

05 • EXPRESSION CONVERSION

Infix to Postfix

In postfix notation, operators are written after their operands. A stack is used to temporarily hold operators.

Operator Precedence

OperatorMeaningPriority
()ParenthesesHighest
^PowerHigh
*, /, %Multiplication / Division / ModulusMedium
+, -Addition / SubtractionLow

Algorithm

  1. Scan the infix expression from left to right.
  2. If the symbol is an operand, add it to the output.
  3. If the symbol is (, push it onto the stack.
  4. If the symbol is ), pop until ( is found.
  5. If the symbol is an operator, pop operators having higher or equal precedence as appropriate, then push the current operator.
  6. After scanning, pop all remaining operators.

Solved Example

InfixA + B * C

Step 1: A → output

Step 2: + → stack

Step 3: B → output

Step 4: * has higher precedence → stack

Step 5: C → output

Step 6: Pop * and +.

Postfix = ABC*+
Another Example(A + B) * C → AB+C*
06 • EXPRESSION CONVERSION

Infix to Prefix

In prefix notation, the operator is written before its operands.

General Method

  1. Reverse the infix expression.
  2. Replace ( with ) and vice versa.
  3. Convert the modified expression to postfix using a stack.
  4. Reverse the resulting postfix expression.

Example

InfixA + B * C
First apply precedence: B*C
Prefix result:
+ A * B C
07 • STACK APPLICATION

Postfix Expression Evaluation

A postfix expression can be evaluated using a stack because no parentheses are required.

Algorithm

  1. Scan the postfix expression from left to right.
  2. If the symbol is an operand, push it.
  3. If the symbol is an operator, pop the required operands.
  4. Apply the operator and push the result.
  5. After the complete scan, the stack top is the final answer.

Solved Example

Expression23*54*+
SymbolActionStack
2Push2
3Push2, 3
*2 × 3 = 66
5Push6, 5
4Push6, 5, 4
*5 × 4 = 206, 20
+6 + 20 = 2626
Answer = 26
08 • SELF-CALLING FUNCTION

Recursion

Definition: Recursion is a technique in which a function calls itself to solve a smaller version of the same problem.

Two Essential Parts

  • Base Case: Condition that stops recursion.
  • Recursive Case: Function calls itself with a smaller/simpler input.

Example: Factorial

n! = n × (n−1)!    and    0! = 1
int factorial(int n)
{
    if (n == 0)
        return 1;

    return n * factorial(n - 1);
}

Working of factorial(4)

factorial(4)
= 4 × factorial(3)
= 4 × 3 × factorial(2)
= 4 × 3 × 2 × factorial(1)
= 4 × 3 × 2 × 1
= 24

Advantages

  • Can make some algorithms shorter and easier to understand.
  • Natural for tree traversal, divide-and-conquer and backtracking.

Limitations

  • Recursive calls use call-stack memory.
  • Too many calls can cause stack overflow.
  • May be slower than an iterative solution because of function-call overhead.
09 • RECURSION TYPE

Tail Recursion

A recursive function is tail-recursive when the recursive call is the last major operation performed by the function.
void print(int n)
{
    if (n == 0)
        return;

    printf("%d ", n);
    print(n - 1);
}

Recursion vs Iteration

RecursionIteration
Uses function callsUses loops
Uses call stackUsually uses less extra memory
Needs a base caseNeeds loop condition
Often elegant for recursive problemsOften efficient for repeated simple operations
10 • IMPORTANT RECURSIVE PROBLEM

Tower of Hanoi

Tower of Hanoi is a recursive problem involving three rods and n disks. The objective is to move all disks from the source rod to the destination rod while following the rules.

Rules

  1. Only one disk can be moved at a time.
  2. Only the top disk of a rod can be moved.
  3. A larger disk cannot be placed on a smaller disk.
Minimum moves = 2ⁿ − 1

Recursive Algorithm

  1. Move n−1 disks from Source to Auxiliary.
  2. Move the largest disk from Source to Destination.
  3. Move n−1 disks from Auxiliary to Destination.
void towerOfHanoi(int n, char source,
                  char auxiliary, char destination)
{
    if (n == 1)
    {
        printf("Move disk 1 from %c to %c\n",
               source, destination);
        return;
    }

    towerOfHanoi(n - 1, source, destination, auxiliary);

    printf("Move disk %d from %c to %c\n",
           n, source, destination);

    towerOfHanoi(n - 1, auxiliary, source, destination);
}
For n = 3Minimum moves = 2³ − 1 = 7
11 • FIFO DATA STRUCTURE

Queue

Definition: A queue is a linear data structure in which insertion is performed at the REAR and deletion is performed at the FRONT. It follows the FIFO (First In, First Out) principle.
Insertion → REAR
[10][20][30][40]
 ↑
FRONT
Deletion ←

Basic Operations

  • Enqueue: Insert an element at rear.
  • Dequeue: Remove an element from front.
  • Front/Peek: View the front element.
  • isEmpty: Check whether queue is empty.
  • isFull: Check whether an array queue is full.

Applications

  • CPU scheduling.
  • Printer queues.
  • Network packet handling.
  • Customer-service systems.
  • Breadth First Search (BFS).
12 • ARRAY IMPLEMENTATION

Queue Using Array

Initial Condition

front = rear = -1

Enqueue

  1. Check whether the queue is full.
  2. If the first insertion, set front = 0.
  3. Increment rear.
  4. Store the item at queue[rear].

Dequeue

  1. Check whether the queue is empty.
  2. Read queue[front].
  3. Increment front.
  4. If the queue becomes empty, reset front and rear appropriately.
C Program — Linear Queue
#include <stdio.h>
#define MAX 5

int queue[MAX];
int front = -1, rear = -1;

void enqueue(int value)
{
    if (rear == MAX - 1)
        printf("Queue Overflow\n");
    else
    {
        if (front == -1)
            front = 0;

        rear++;
        queue[rear] = value;
    }
}

void dequeue()
{
    if (front == -1 || front > rear)
        printf("Queue Underflow\n");
    else
    {
        printf("Deleted: %d\n", queue[front]);
        front++;

        if (front > rear)
            front = rear = -1;
    }
}

void display()
{
    if (front == -1)
        printf("Queue is Empty\n");
    else
        for (int i = front; i <= rear; i++)
            printf("%d ", queue[i]);
}

int main()
{
    enqueue(10);
    enqueue(20);
    enqueue(30);

    display();
    dequeue();

    return 0;
}
13 • LINKED IMPLEMENTATION

Queue Using Linked List

A linked-list queue uses two pointers: front and rear.

FRONT                         REAR
  ↓                             ↓
[10 | next] → [20 | next] → [30 | NULL]

Enqueue

Create a node and attach it after the current rear. Then move rear to the new node.

Dequeue

Remove the node pointed to by front and move front to the next node.

Key idea: Enqueue happens at rear; dequeue happens at front.
14 • IMPROVED QUEUE

Circular Queue

A circular queue connects the last position of the array back to the first position, allowing previously unused positions to be reused.
        ┌──────────────────────┐
        ↓                      │
[0] [1] [2] [3] [4] ──────────┘

Why Circular Queue?

In a simple linear array queue, after deletions, free spaces may appear at the beginning while rear reaches the last index. Circular queue reuses these spaces.

Important Conditions

Empty: front == -1
Full: (rear + 1) % MAX == front

Enqueue Logic

  1. If full, report overflow.
  2. If empty, set front = rear = 0.
  3. Otherwise set rear = (rear + 1) % MAX.
  4. Insert the value at rear.

Dequeue Logic

  1. If empty, report underflow.
  2. Save/remove the front element.
  3. If front == rear, reset both to -1.
  4. Otherwise set front = (front + 1) % MAX.
Core Circular Queue Conditions
if ((rear + 1) % MAX == front)
    printf("Queue Full");

rear = (rear + 1) % MAX;

front = (front + 1) % MAX;
15 • DOUBLE ENDED QUEUE

Deque — Double Ended Queue

A deque is a queue in which insertion and deletion can be performed at both the front and rear ends.
Front ⇄ [10][20][30][40] ⇄ Rear

Operations

  • Insert at front.
  • Insert at rear.
  • Delete from front.

16 • PRIORITY-BASED QUEUE

Priority Queue

A priority queue is a queue in which elements are processed according to their priority rather than simply according to arrival order.

Example

In a hospital emergency system, a critical patient may be served before a less critical patient even if the latter arrived earlier.

Basic Operations

  • Insert: Add an element with its priority.
  • Delete: Remove the element having the highest/required priority.
  • Peek: View the highest-priority element.

Types

  • Ascending priority queue.
  • Descending priority queue.
Exam point: Clearly mention that priority determines service order. If two elements have the same priority, their order may be handled according to the implementation's tie rule.
