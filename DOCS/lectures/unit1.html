01 • FOUNDATION

Basic Terminology

Before learning data structures, we need to understand the basic terms used to describe data.

Data

Definition: Data means raw facts, values or observations that can be processed by a computer.
Example 10, 20, 30, "Shubham", "Computer Science", 85

Information

Definition: Information is meaningful data obtained after processing or organizing raw data.
Example Marks = 80, 75, 90 → Average = 81.67%.
The marks are data; the calculated average is information.

Data Item

A data item is a single meaningful unit of data.

ExampleRoll No = 101, Name = Shubham, Marks = 85. Each value is a data item.

Field

A field is an individual attribute of a record.

Example Student record: Roll No | Name | Marks. Roll No, Name and Marks are fields.

Record

A record is a collection of related fields belonging to one entity.

Example101 | Shubham | CSE | 85 is one student record.

File

A file is a collection of related records.

ExampleA student file may contain records of hundreds of students.
Remember: Data → Data Item → Field → Record → File → Database.
02 • ORGANIZATION

Elementary Data Organization

Data organization means arranging data in memory or storage so that it can be accessed, processed and maintained efficiently.

Data → Data Item → Field → Record → File → Database

A good organization method makes searching, insertion, deletion and updating easier. Data structures provide systematic ways to organize data inside a program.

04 • PROBLEM SOLVING

Algorithm

Definition: An algorithm is a finite, step-by-step procedure used to solve a particular problem.

Example: Addition of Two Numbers

  1. Start.
  2. Read A and B.
  3. Calculate Sum = A + B.
  4. Display Sum.
  5. Stop.
C Implementation
#include <stdio.h>

int main()
{
    int a, b, sum;

    scanf("%d %d", &a, &b);

    sum = a + b;

    printf("%d", sum);

    return 0;
}

Characteristics of a Good Algorithm

  • Input: It may have zero or more inputs.
  • Output: It should produce at least one meaningful result.
  • Definiteness: Every step should be clear and unambiguous.
  • Finiteness: It must terminate after a finite number of steps.
  • Effectiveness: Each operation should be practical and executable.
05 • PERFORMANCE

Algorithm Efficiency

Algorithm efficiency describes how much computational time and memory an algorithm needs as the input size increases.

Two algorithms may solve the same problem but may require very different amounts of time or memory. We therefore compare algorithms using complexity.

Example: Searching Searching 100 values one-by-one may require up to 100 checks. A binary-search approach on sorted data can reduce the number of checks dramatically.
06 • COMPLEXITY

Time Complexity

Definition: Time complexity describes how the number of basic operations performed by an algorithm grows with input size n.

Time complexity does not mean exact clock time. It describes the growth of computational work.

O(1) — Constant Time

int x = arr[5];

Accessing a particular array index takes approximately constant time, independent of n.

Complexity: O(1)

O(n) — Linear Time

for(int i = 0; i < n; i++)
{
    printf("%d", i);
}

The loop executes n times.

Complexity: O(n)

O(n²) — Quadratic Time

for(int i = 0; i < n; i++)
{
    for(int j = 0; j < n; j++)
    {
        printf("%d %d", i, j);
    }
}

The outer loop runs n times and the inner loop runs n times for each outer iteration.

n × n = n² → O(n²)

Common Complexities

O(1)Constant
O(log n)Logarithmic
O(n)Linear
O(n log n)Linearithmic
O(n²)Quadratic
O(n³)Cubic
O(2ⁿ)Exponential
O(n!)Factorial
Exam point: When finding asymptotic complexity, lower-order terms and constant multipliers are ignored. For example, 3n² + 5n + 10 has order n².
07 • MEMORY

Space Complexity

Definition: Space complexity describes how much memory an algorithm requires as the input size increases.

Constant Extra Space — O(1)

int x;
int y;
int sum = x + y;

Only a fixed number of variables are used, so the extra space is O(1).

Linear Space — O(n)

int arr[n];

The required storage grows with n, so the space complexity is O(n).

Remember: Time asks “How much work?” and space asks “How much extra memory?”
08 • MATHEMATICAL ANALYSIS

Asymptotic Notations — O, Ω and Θ

Big O — O()

Big O represents an asymptotic upper bound. It describes an upper growth limit for the running time or resource usage.
Example f(n) = 3n² + 5n + 10
For large n, n² dominates n and constants, so the order is O(n²).

Omega — Ω()

Omega represents an asymptotic lower bound.
Example In linear search, if the required element is found at the first position, only one comparison may be required. This gives a best-case lower-bound order of Ω(1).

Theta — Θ()

Theta represents a tight asymptotic bound, meaning the growth is bounded above and below by the same order.
Example 3n² + 5n + 10 = Θ(n²).
NotationMeaningEasy Memory Trick
OUpper boundMaximum growth / upper limit
ΩLower boundMinimum growth / lower limit
ΘTight boundSame asymptotic order
Important: In introductory DSA, O is often associated with worst-case, Ω with best-case and Θ with exact/tight order. Technically, these notations describe mathematical bounds, not merely cases.
09 • DESIGN CONCEPT

Time-Space Tradeoff

Time-space tradeoff means using additional memory to reduce execution time, or saving memory at the cost of additional computation.
More Space ↔ Less Time    |    Less Space ↔ More Time

Example

Suppose we repeatedly search for values. A hash table may use extra memory but provide much faster lookup than repeatedly scanning an array.

Simple comparison Method 1: Less extra space, repeated searching → more time.
Method 2: Extra lookup structure → more space, faster searching.
10 • ABSTRACTION

Abstract Data Type (ADT)

Definition: An Abstract Data Type defines what data operations are available and what those operations should do, without specifying the internal implementation.

Example: Stack ADT

A stack may provide these operations:

  • push() — insert an element.
  • pop() — remove the top element.
  • peek() — inspect the top element.
  • isEmpty() — check whether the stack is empty.
ADT = WHAT operations are available
Implementation = HOW those operations are performed

A stack can be implemented using an array or a linked list. The ADT remains conceptually the same.

11 • LINEAR DATA STRUCTURE

Arrays

Definition: An array is a collection of elements of the same data type stored in contiguous memory locations.

Declaration

int marks[5];

Initialization

int arr[5] = {10, 20, 30, 40, 50};
Indexing arr[0] = 10
arr[1] = 20
arr[2] = 30
arr[3] = 40
arr[4] = 50
C array indexing starts from 0, not 1.

Array Access

printf("%d", arr[2]);

The value at index 2 is 30. Direct index access is O(1).

Insertion

If an element is inserted in the middle, later elements must be shifted.

10 20 30 40 → insert 25 at index 2 → 10 20 25 30 40

Middle insertion is generally O(n).

Deletion

10 20 30 40 50 → delete 30 → 10 20 40 50

Elements after the deleted element may need to shift left, so deletion is generally O(n).

Advantages

  • Fast random access using an index.
  • Simple representation.
  • Good cache locality because elements are contiguous.

Limitations

  • Insertion and deletion in the middle can be expensive.
  • Traditional fixed-size arrays have a fixed capacity.

13 • MEMORY REPRESENTATION

Row-Major and Column-Major Representation

Row-Major Order

In row-major order, all elements of the first row are stored first, followed by all elements of the second row, and so on. 

1  2  3
4  5  6
7  8  9

Memory:
1 → 2 → 3 → 4 → 5 → 6 → 7 → 8 → 9

C language uses row-major order for multidimensional arrays.

Row-Major Address Formula

Address(A[i][j]) = Base + [(i × Number of Columns) + j] × W

Where Base = starting address, i = row index, j = column index, and W = size of each element in bytes.

Solved Example

Suppose A[3][4], Base = 1000, W = 4 bytes. Find the address of A[2][1].

Address = 1000 + [(2 × 4) + 1] × 4
= 1000 + 9 × 4
= 1036

Column-Major Order

Column-major stores the complete first column, then the second column, then the third column. 

1  2  3
4  5  6
7  8  9

Memory:
1 → 4 → 7 → 2 → 5 → 8 → 3 → 6 → 9
Column-major Address(A[i][j]) = Base + [(j × Number of Rows) + i] × W
14 • MEMORY OPTIMIZATION

Sparse Matrix

A sparse matrix is a matrix in which most of the elements are zero.

Example

0  0  5  0
0  0  0  0
3  0  0  0
0  0  0  7

This 4 × 4 matrix has 16 total positions but only 3 non-zero values. Storing every zero wastes memory.

Triplet Representation

A common representation stores only row, column and value of each non-zero element. 

Rows  Columns  Non-zero
 4       4          3

Row  Column  Value
 0      2      5
 2      0      3
 3      3      7
Why use it? Sparse representation reduces storage when the number of non-zero elements is much smaller than the total number of matrix positions.
15 • DYNAMIC DATA STRUCTURE

Linked Lists

A linked list is a dynamic collection of nodes where each node contains data and one or more links to other nodes.

Basic Node

struct Node
{
    int data;
    struct Node *next;
};

The first field stores the value. The pointer stores the address of the next node.

Singly linked-list structure 
[10 | next] → [20 | next] → [30 | NULL]

Array vs Linked List

FeatureArrayLinked List
MemoryContiguousNon-contiguous nodes

Index accessO(1)O(n)
Beginning insertionUsually O(n)O(1)
Extra pointer memoryNoYes
16 • LINKED LIST TYPE

Singly Linked List

Each node has two parts: data and a pointer to the next node. Traversal normally happens in the forward direction.

Complete C Example

#include <stdio.h>
#include <stdlib.h>

struct Node
{
    int data;
    struct Node *next;
};

int main()
{
    struct Node *head;
    struct Node *second;
    struct Node *third;

    head = (struct Node*)malloc(sizeof(struct Node));
    second = (struct Node*)malloc(sizeof(struct Node));
    third = (struct Node*)malloc(sizeof(struct Node));

    head->data = 10;
    head->next = second;

    second->data = 20;
    second->next = third;

    third->data = 30;
    third->next = NULL;

    struct Node *temp = head;

    while(temp != NULL)
    {
        printf("%d ", temp->data);
        temp = temp->next;
    }

    free(third);
    free(second);
    free(head);

    return 0;
}

Line-by-line Explanation

  1. #include <stdio.h> provides printf().
  2. #include <stdlib.h> provides malloc() and free().
  3. struct Node defines the structure of one node.
  4. int data; stores the node's actual value.
  5. struct Node *next; stores the address of the next node.
  6. head will point to the first node.
  7. malloc(sizeof(struct Node)) dynamically allocates memory for a node.
  8. head->data = 10 stores 10 in the first node.
  9. head->next = second connects the first node to the second node.
  10. The same process connects the second node to the third node.
  11. third->next = NULL marks the end of the list.
  12. temp = head starts traversal from the first node.
  13. The while loop continues until temp becomes NULL.
  14. temp = temp->next moves to the next node.
  15. free() releases dynamically allocated memory.

Traversal Complexity

To visit all n nodes, we process each node once.

Traversal = O(n)

Insertion at Beginning

newNode->next = head;
head = newNode;

First, the new node points to the current head. Then head is changed to the new node.

Insertion at beginning = O(1)

Insertion at End

Without a tail pointer, we traverse until the last node and then attach the new node.

Typical complexity without tail pointer = O(n)

Deletion

To delete a middle node, the previous node is connected to the node after the deleted node. 

previous->next = current->next;
free(current);
17 • LINKED LIST TYPE

Doubly Linked List

A doubly linked-list node contains three parts: previous pointer, data and next pointer. 
struct Node
{
    int data;
    struct Node *prev;
    struct Node *next;
};
Structure 
NULL ← 10 ⇄ 20 ⇄ 30 → NULL

The prev pointer allows backward traversal, while next allows forward traversal.

Advantages

  • Forward and backward traversal.
  • Deletion can be convenient when a node reference is available.
  • Useful for navigation structures such as browser history.

Disadvantage

Each node needs an additional pointer, so more memory is required.

18 • LINKED LIST TYPE

Circular Linked List

In a circular linked list, the last node points back to the first node instead of pointing to NULL.
Structure 
10 → 20 → 30
↑         ↓
└─────────┘

The connection is commonly created using:

last->next = head;

Because there is no NULL at the end, traversal must be controlled carefully, often by stopping when we reach the starting node again.

19 • APPLICATION OF LINKED LIST

Polynomial Operations

A polynomial can be represented using linked-list nodes where every node stores a coefficient and an exponent/power.

Example

Polynomial:

5x³ + 4x² + 2x + 7

Linked-list representation:

[5,3] → [4,2] → [2,1] → [7,0] → NULL

Here [5,3] means coefficient = 5 and power = 3, representing 5x³.

Node Structure

struct Node
{
    int coeff;
    int power;
    struct Node *next;
};

Polynomial Addition

Suppose:

P1 = 5x² + 4x + 3
P2 = 3x² + 2x + 1

Terms having the same power are added:

5x² + 3x² = 8x²
4x + 2x = 6x
3 + 1 = 4
Result = 8x² + 6x + 4

Polynomial Addition Logic

  1. Compare the powers of the current terms.
  2. If both powers are equal, add their coefficients.
  3. If power of P1 is greater, copy P1's term to the result.
  4. If power of P2 is greater, copy P2's term to the result.
  5. Continue until both lists are processed.

Polynomial Multiplication

Example:

(2x + 3)(x + 4)

Multiply every term of the first polynomial by every term of the second:

2x × x = 2x²
2x × 4 = 8x
3 × x = 3x
3 × 4 = 12

Combine like terms:

2x² + 8x + 3x + 12 = 2x² + 11x + 12
