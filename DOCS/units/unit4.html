01 • FOUNDATION

What is a Graph?

Definition: A graph is a non-linear data structure consisting of a set of vertices and a set of edges connecting those vertices.
G = (V, E)

V = set of vertices (nodes), E = set of edges (connections).

Example: V = {A, B, C, D} and E = {AB, AC, BC, BD}

Real-life examples

  • Google Maps: cities/locations are vertices; roads are edges.
  • Social networks: people are vertices; friendships/follows are edges.
  • Computer networks: devices are vertices; network links are edges.

Vertex / Node

A vertex is a point or node in a graph.

Edge

An edge is a connection between two vertices.

Adjacent Vertices

Two vertices connected directly by an edge are called adjacent.

Cycle

A path that starts and ends at the same vertex.

Connected Graph

An undirected graph is connected when every vertex is reachable from every other vertex.

Disconnected Graph

A graph is disconnected when at least one pair of vertices has no path between them.

    'A': ['B', 'C'],
    'B': ['A', 'D'],

07 • TRAVERSAL

DFS — Depth First Search

Idea: DFS goes as deep as possible along a branch before backtracking.
A
/     \\
B
C
/ \\
D
E

One possible DFS traversal from A is:

A → B → D → E → C

DFS uses

  • Recursion or an explicit stack.
  • Connected components.
  • Cycle detection.
  • Maze/path exploration and topological sorting.
Python — Recursive DFS
def DFS(graph, node, visited):
    if node not in visited:
        print(node)
        visited.add(node)

        for neighbour in graph[node]:
            DFS(graph, neighbour, visited)

graph = {
    'A': ['B', 'C'],
    'B': ['D', 'E'],
    'C': [],
    'D': [],
    'E': []
}

visited = set()
DFS(graph, 'A', visited)
DFS complexity = O(V + E)

BFS — Breadth First Search

Idea: BFS visits the graph level by level. It normally uses a queue.

B

Level 1

D

Level 2

BFS from A → A, B, C, D, E
Python — BFS using Queue
from collections import deque

graph = {
    'A': ['B', 'C'],
    'B': ['D', 'E'],
    'C': [],
    'D': [],
    'E': []
}

visited = set()
queue = deque(['A'])

while queue:
    node = queue.popleft()

    if node not in visited:
        print(node)
        visited.add(node)

        for neighbour in graph[node]:
            queue.append(neighbour)
BFS complexity = O(V + E)
09 • CONNECTIVITY

Connected Components

A connected component is a maximal group of vertices in which each vertex is reachable from the other vertices in that group.

A
—
B
    
C
—
D

Component 1 = {A, B}    Component 2 = {C, D}

Basic method

  1. Start with all vertices unvisited.
  2. Pick an unvisited vertex.
  3. Run DFS or BFS from it and mark all reachable vertices.
  4. Increase component count and repeat until all vertices are visited.
10 • SPANNING TREES

Spanning Tree

A spanning tree is a connected, acyclic subgraph that contains all vertices of the original connected graph.
For V vertices, a spanning tree has exactly V − 1 edges.
ExampleA graph with 5 vertices has a spanning tree with exactly 4 edges.

Minimum Spanning Tree (MST)

A minimum spanning tree is a spanning tree whose total edge weight is minimum among all possible spanning trees.

The two major MST algorithms in this unit are Prim's and Kruskal's.

11 • MST ALGORITHM

Prim's Algorithm

Idea: Start from one vertex and repeatedly choose the minimum-weight edge that connects the current tree to an unvisited vertex.
A

B
A
—3—
C
B
—1—
D
C
—4—

Steps

  1. Select a starting vertex.
  2. Mark it visited.
  3. Find the smallest edge from a visited vertex to an unvisited vertex.
  4. Add that edge and the new vertex to the tree.
  5. Repeat until all vertices are included.
ExampleStart A → choose AB(2) → choose BD(1) → choose AC(3). Total MST weight = 2 + 1 + 3 = 6.
Simple Prim: O(V²)   |   Priority Queue version: O(E log V)
12 • MST ALGORITHM

Kruskal's Algorithm

Idea: Sort all edges by weight and keep adding the smallest edge if it does not create a cycle.

Steps

  1. List all edges.
  2. Sort edges in increasing order of weight.
  3. Take the smallest edge.
  4. Add it only if it does not form a cycle.
  5. Stop when V − 1 edges have been selected.
ExampleIf sorted edges are AB=1, BD=2, CD=3, AC=4, select AB, BD and CD if they connect new components without forming a cycle. Total = 6.
Typical Kruskal complexity = O(E log E)
Advanced point: Kruskal is commonly implemented with Disjoint Set Union (Union-Find) to efficiently detect cycles.

14 • REACHABILITY

Warshall's Algorithm

Warshall's algorithm finds the transitive closure of a directed graph: whether a path exists between every pair of vertices.
ExampleIf A → B and B → C, then A can reach C through B even when there is no direct A → C edge.

Core recurrence

R[i][j] = R[i][j] OR (R[i][k] AND R[k][j])

Python-style implementation

for k in range(n):
    for i in range(n):
        for j in range(n):
            graph[i][j] = graph[i][j] or (
                graph[i][k] and graph[k][j]
            )

Example matrix

ABC
A010
B001
C000

Because A → B → C, the final reachability matrix will contain A → C = 1.

Warshall time = O(V³)   |   Space = O(V²)
15 • SHORTEST PATH

Dijkstra's Algorithm

Purpose: Finds shortest distances from one source vertex to all other vertices in a weighted graph with non-negative edge weights.

Key idea — Relaxation

If reaching a neighbour through the current vertex gives a smaller distance, update the neighbour's distance.

newDistance = distance[current] + edgeWeight

—4—
B
A
—2—
C
C
—3—
D
D
—1—
B

Example from source A

  1. Initialize A = 0 and all other distances = ∞.
  2. From A: B = 4 and C = 2.
  3. Choose the smallest unvisited distance: C = 2.
  4. Through C, D = 2 + 3 = 5.
  5. Through D, B would be 5 + 1 = 6, but B is already 4, so keep B = 4.
Final distances: A=0, B=4, C=2, D=5
Python — simple Dijkstra implementation
graph = {
    'A': {'B': 4, 'C': 2},
    'B': {'A': 4, 'D': 1},
    'C': {'A': 2, 'D': 3},
    'D': {'B': 1, 'C': 3}
}

distance = {
    'A': 0,
    'B': float('inf'),
    'C': float('inf'),
    'D': float('inf')
}

visited = set()

for _ in range(len(graph)):
    current = None

    for node in graph:
        if node not in visited:
            if current is None or distance[node] < distance[current]:
                current = node

    visited.add(current)

    for neighbour, weight in graph[current].items():
        new_distance = distance[current] + weight

        if new_distance < distance[neighbour]:
            distance[neighbour] = new_distance

print(distance)
Important: Standard Dijkstra should not be used when negative edge weights are present. Bellman-Ford is a common alternative for graphs that may contain negative weights.
Simple Dijkstra = O(V²)   |   Priority Queue = O((V+E) log V)

FINAL REVISION

Unit 4 — Quick Revision

One-line memory tricks

  • Graph: G = (V, E)
  • Undirected: edges have no direction.
  • Directed: edges have direction.
  • Weighted: edges carry values such as cost/distance.
  • Adjacency Matrix: V×V table; space O(V²).
  • Adjacency List: each vertex stores neighbours; space O(V+E).
  • DFS: Deep first → stack/recursion.
  • BFS: Broad first → queue.
  • Connected Components: groups of mutually reachable vertices.
  • Spanning Tree: connected + acyclic + all vertices + V−1 edges.
  • Prim: grow one minimum spanning tree.
  • Kruskal: sort edges and add the smallest non-cycle edge.
  • Warshall: transitive closure / reachability.
  • Dijkstra: shortest paths from one source, non-negative weights.

Most important exam questions

  1. Define graph and explain basic terminology.
  2. Explain adjacency matrix and adjacency list with examples.
  3. Explain DFS and BFS with algorithms and complexity.
  4. What are connected components?

  6. Explain Prim's algorithm with a suitable example.
  7. Explain Kruskal's algorithm and cycle detection.
  8. Differentiate Prim and Kruskal.
  9. Explain Warshall's algorithm and transitive closure.
  10. Explain Dijkstra's algorithm with relaxation.
  11. Differentiate BFS and Dijkstra.
  12. Write complexity of DFS, BFS, Prim, Kruskal, Warshall and Dijkstra.
